#### Terraform Labs & Exercises
This repository contains my Terraform labs, exercises, and practice projects.

The purpose of this repository is to learn and build practical experience with Infrastructure as Code (IaC) using Terraform. Each lab focuses on creating, configuring, and managing different cloud infrastructure resources using Terraform configuration files.

#### What You'll Find Here
The repository will contain different Terraform exercises covering areas such as:

- Creating and managing AWS resources
- Working with Terraform providers
- Creating infrastructure using .tf configuration files
- Using variables and outputs
- Managing Terraform state
- Using Terraform modules
- Configuring resource dependencies
- Running terraform init, plan, apply, and destroy
- Updating and modifying existing infrastructure
- Practicing Infrastructure as Code principles

#### Example Resources
Some of the resources created during these labs may include:

- Amazon S3 buckets
- EC2 instances
- VPCs and networking resources
- IAM resources
- Security groups
 - Other AWS services and infrastructure components

#### Tools Used
- Terraform
- AWS
- AWS CLI
- WSL / Ubuntu
- Git & GitHub
- Visual Code

#### Purpose
This repository is primarily a learning and practice environment. The goal is to develop a better understanding of Terraform and gain hands-on experience creating and managing cloud infrastructure through code.
